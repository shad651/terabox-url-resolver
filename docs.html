API Documentation

A lightweight REST API for extracting HLS streaming URLs from Terabox share links. {% if not cookie_set %}
⚠ Cookie is not configured — see setup instructions below. {% endif %}

GET /api

Resolve a Terabox share URL and return the HLS streaming URL.

Query Parameters

NameTypeRequiredDescription
url string Yes The Terabox share URL. Supported domains: terabox.com, 1024terabox.com, teraboxapp.com, 4funbox.com, nephobox.com, and more.
mode string No Response shape. stream (default) returns only streaming-relevant fields. info returns full file metadata including size, path, surl, and download URL.

Example Request

curl "http://localhost:5000/api?url=https://1024terabox.com/s/1LNr3tyl5pI5KUM8BecGtyQ&mode=stream"

Response — stream mode (200 OK)

{
  "success": true,
  "data": {
    "streaming_url": "https://d-jp0xc-vd.pcs.baidu.com/file/.../playlist.m3u8?...",
    "filename": "movie_720p.mp4",
    "is_video": true,
    "cached": false
  }
}

Response — info mode (200 OK)

{
  "success": true,
  "data": {
    "streaming_url": "https://d-jp0xc-vd.pcs.baidu.com/.../playlist.m3u8?...",
    "download_url": "https://d-jp0xc-vd.pcs.baidu.com/file/...?...",
    "filename": "movie_720p.mp4",
    "size": 524288000,
    "path": "/movie_720p.mp4",
    "surl": "1LNr3tyl5pI5KUM8BecGtyQ",
    "is_video": true,
    "cached": false
  }
}

Error Responses

// 400 — Missing or invalid input
{
  "success": false,
  "error": "Missing required parameter: url"
}

// 502 — Upstream resolution failed
{
  "success": false,
  "error": "Failed to resolve: Terabox share-list error: errno=-20 msg=..."
}

Setup — Getting your ndus Cookie

The API needs your Terabox session cookie to authenticate against the Terabox API. To get it:

  1. Log in to terabox.com or 1024terabox.com in your browser.
  2. Open Developer Tools (F12) → Application tab → Storage → Cookies.
  3. Select the Terabox domain and find the cookie named ndus.
  4. Copy its Value.
  5. Open the .env file in the project root.
  6. Paste it as: COOKIE_JSON=your_ndus_token_here
  7. Restart the server.
Tip: You can also pass a full JSON cookie object if you have one: COOKIE_JSON={"ndus": "...", "BDCLND": "..."}

Configuration Reference

All configuration is via environment variables (or a .env file):

VariableDefaultDescription
COOKIE_JSON — Your Terabox ndus token, or a JSON object of cookies. Required for resolution to work.
PROXY_URL — Optional Cloudflare Worker / reverse proxy URL. All upstream Terabox calls are routed through <PROXY_URL>?url=<terabox_url>.
PORT 5000 Port to listen on.
HOST 0.0.0.0 Bind address. Use 127.0.0.1 for local-only access.
DEBUG 0 Set to 1 to enable Flask debug mode (auto-reload on file changes).
LOG_LEVEL INFO Logging verbosity. One of DEBUG, INFO, WARNING, ERROR.

Usage Examples

1. Basic curl request

curl "http://localhost:5000/api?url=https://1024terabox.com/s/1LNr3tyl5pI5KUM8BecGtyQ"

2. Get the streaming URL and pipe it into ffplay

STREAM_URL=$(curl -s "http://localhost:5000/api?url=https://1024terabox.com/s/1LNr3tyl5pI5KUM8BecGtyQ" \
  | python -c "import sys, json; print(json.load(sys.stdin)['data']['streaming_url'])")

ffplay "$STREAM_URL"

3. Python client (requests)

import requests

resp = requests.get("http://localhost:5000/api", params={
    "url": "https://1024terabox.com/s/1LNr3tyl5pI5KUM8BecGtyQ",
    "mode": "info",
})
data = resp.json()
if data["success"]:
    print("Streaming URL:", data["data"]["streaming_url"])
    print("Filename:", data["data"]["filename"])
    print("Size:", data["data"]["size"], "bytes")

4. JavaScript (browser / Node)

const url = "https://1024terabox.com/s/1LNr3tyl5pI5KUM8BecGtyQ";
const resp = await fetch(`http://localhost:5000/api?url=${encodeURIComponent(url)}&mode=stream`);
const json = await resp.json();

if (json.success) {
  console.log("Streaming URL:", json.data.streaming_url);
  // Play it with hls.js, video.js, or paste into VLC
}
